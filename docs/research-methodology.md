# Research Methodology

## Primary research question

How much useful private edge-AI capability can be obtained from commodity Android hardware costing less than US$50 when cloud infrastructure is unavailable or untrusted?

## Measurements

Experiments should record tokens per second, time to first token, model load time, retrieval latency, memory use, storage consumption, temperature, battery consumption, and successful task completion.

Every benchmark should record device model, firmware and Android versions, model name and hash, runtime version, test parameters, and raw output.
